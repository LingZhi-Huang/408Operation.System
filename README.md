# 考研 408《操作系统》图解笔记

> 面向零基础起步的考研同学的**全图解操作系统笔记**：每一章都是「Python 绘制的 PNG 插图（嵌入正文） + 超详细 Markdown 教材 + 大量对比表格 + 计算公式 + 真题风格例题 + 自测题」。

- `第N章_xxx.md` —— 正文（**图片已用绝对路径嵌入**）
- `figures/` —— 该章全部 PNG 插图

## 学习顺序（建议）

按 `第0章 → 第1章 → 第2章 → 第3章 → 第4章 → 第5章` 顺序精读，其中：
- **第2章 进程与线程**：分值最高、最难，PV 与调度是 408 大题常客。
- **第3章 内存管理**：以“地址变换 + 置换算法”计算为重。
- **第4章 文件管理**：细节最多，混合索引 + 磁盘调度 + 空闲管理是计算题三巨头。
- **第5章 输入输出**：偏概念，掌握四种控制方式与缓冲计算即可。
